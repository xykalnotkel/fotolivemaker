## 1. Tentang aplikasi ini

Live Photo Maker adalah perangkat lunak gratis dan open source yang mengubah
file video menjadi **Motion Photo** (format Google) — satu file JPEG yang berisi
klip video di dalamnya.

Aplikasi ini berjalan **sepenuhnya offline di perangkatmu**. Tidak ada file yang
diunggah ke server mana pun.

apa pun, sesuai Lisensi MIT yang menyertainya.

Secara khusus, **tidak ada jaminan bahwa:**
- File hasil konversi akan dikenali sebagai "Live Photo" oleh TikTok, Instagram,

- Fitur ini akan tetap bekerja setelah aplikasi pihak ketiga tersebut diperbarui
- Aplikasi kompatibel dengan semua merek dan versi Android

Dukungan Motion Photo **bervariasi per perangkat dan per versi aplikasi**.
Ini bukan API resmi dari TikTok maupun Google, melainkan pemanfaatan format
terbuka yang bisa berubah sewaktu-waktu di luar kendali pengembang.
